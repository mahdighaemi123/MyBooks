# 🧙‍♂️ An Adventure with Python

> A journey-based collection of Python exercises and real-world examples — directly from the book “An Adventure with Python”.

---

## 🚀 About This Repository

This repository contains all code examples and exercises from the book “An Adventure with Python”.

The content is carefully structured to guide you step-by-step — from your very first line of code to building more advanced, real-world projects.

Each chapter represents a stage in your journey, and each part contains focused exercises to strengthen your skills.

---

## 🧭 Repository Structure

- 📁 `Sxx` → Chapter number
- 📂 `Pxx` → Part inside each chapter
- 🧪 `Sxx.5-SHADOW-LIB` → Bonus & challenge exercises
- 🐍 `.py` → Python scripts

📌 Example:
```
S03/P02/1.numvars_init.py
```
